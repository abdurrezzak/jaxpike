# jaxpike documentation site

[Docusaurus 3](https://docusaurus.io/). **Needs Node 20 or newer.**

```bash
npm install
npm start          # dev server with hot reload on http://localhost:3000
npm run build      # production build; fails on any broken internal link
npm run serve      # serve the production build locally
```

CI builds this on every push. `onBrokenLinks: 'throw'` is set deliberately, so a build failure
usually means a cross-reference points at a page that moved or no longer exists.

## Layout

| Path | What it is |
|---|---|
| `docs/` | all content; the sidebar order is `sidebars.ts`, not the filesystem |
| `src/pages/index.tsx` | landing page |
| `src/css/custom.css` | palette, matched to `jaxpike.viz` |
| `static/img/figures/` | **copies** of `docs/figures/` from the repository root |

## Figures

Figures are generated by the library, not drawn by hand:

```bash
cd .. && PYTHONPATH=. python examples/gallery.py     # writes docs/figures/
cp ../docs/figures/*.png static/img/figures/
```

Each figure exists in a light and a dark variant. Pages include both and let CSS pick, via the
`figure-light` / `figure-dark` classes in `src/css/custom.css`, so a reader in dark mode does not
get a white rectangle.

## Before publishing

`GITHUB_ACCOUNT` at the top of `docusaurus.config.ts` drives the GitHub links, the Pages URL
and `organizationName`. It must stay in sync with `[project.urls]` in `pyproject.toml`.

`baseUrl` is `/jaxpike/`, which is correct for a project Pages site at
`<account>.github.io/jaxpike/`. Serving from a custom domain or a `<account>.github.io`
repository means setting it to `/`.

## Writing conventions

The numbers in these docs are measured, not estimated, and several of them are deliberately
unflattering — the 2.5× end-to-end figure that undercuts the 119× microbenchmark, the negative
result on reset-based parallel-in-time, the memory finding that weakened the argument for the
project's own founding thesis. Keep it that way. If you change a number, change it because you
re-measured it, and update `benchmarks/README.md` in the same commit.
